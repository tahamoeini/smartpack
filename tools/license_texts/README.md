# SPDX fallback texts

These canonical license texts are copied verbatim from the SPDX License List data repository. The snapshot used for this bundle is [commit 31ba1a50](https://github.com/spdx/license-list-data/tree/31ba1a50e5397e00a304dbadc76531740e89ee48/text). The filenames match SPDX identifiers. The notice generator uses these texts only when a dependency declares an SPDX license but its published package omits the corresponding license file.

The license terms apply to the third-party packages that declare them; their presence here does not change the license of SmartPack-authored code.
